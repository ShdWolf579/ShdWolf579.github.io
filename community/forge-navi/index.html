Public Desktop Beta • v0.2.0

Forge-Navi is becoming a launch-and-go app.

Forge-Navi Community now includes a Windows desktop beta over the public Core. Choose a Forge custom folder, click Audit, review RED / YELLOW / GREEN findings, open the affected script, generate token handoffs, and build a gated package without living in PowerShell.

Quick start

Download install.ps1, open PowerShell in the download folder, then run:

powershell -ExecutionPolicy Bypass -File .\install.ps1

cd .\Forge-Navi-Community
py -3 forge_navi_community.py audit demo/custom --report demo/audit-report.json
py -3 forge_navi_community.py handoff demo/custom demo/generated-token-requirements.json
py -3 token_navi_community.py validate demo/generated-token-requirements.json
py -3 forge_navi_community.py package demo/custom dist/demo-forge-package.zip

What you can use it for

  • Scan Forge-style custom card/token scripts for structural problems.
  • Catch duplicate names, malformed SVar entries, missing token scripts, and basic unresolved references.
  • Generate a machine-readable token-production handoff.
  • Bind visual approval to the exact PNG bytes with SHA-256 and dimensions.
  • Block packaging when structural errors remain and produce a hash manifest when clean.

What is intentionally not public

The production Navi repositories have a much larger semantic knowledge base, learned failure/repair history, upstream Forge research, active project state, and rendering configuration. This release is meant to be genuinely useful while keeping that private production corpus private.
