Spotify Web — Liked Songs Sorter

A Violentmonkey userscript for Spotify's web player that loads your full Liked Songs library, adds sorting and search, and lets you play a track without leaving the custom sorted view. Built because Spotify's web player doesn't provide normal Liked Songs sorting.

USERSCRIPT • v0.7.0
Automatic Install Manual Install / View Source

Brave + some Violentmonkey builds may crash when opening userscript install links directly. If that happens, use Manual Install / View Source instead.

  1. Install Violentmonkey in your browser.
  2. For automatic install, click Automatic Install and approve the userscript.
  3. If the install link crashes your browser, open Manual Install / View Source, copy the script, then open Violentmonkey → Dashboard → New, replace the template, and save.
  4. Open Spotify Web Player → Liked Songs.
  5. Click Liked Sort → Refresh library.
  6. Sort/search the full library and click songs to play them without closing the sorter.

Unofficial project. Not affiliated with or endorsed by Spotify.
